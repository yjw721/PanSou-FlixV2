# PanSou Flix

Emby 风格的网盘资源影视墙前端。把 [PanSou](https://so.252035.xyz/) 的搜索结果从「链接列表」重构成「海报墙」。

纯静态 SPA，Vite + Vue 3，直连后端 API，无需自建服务器。

## 特性

**影视墙浏览**
- 海报墙 / 列表双视图，骨架屏 + 懒加载 + 无限滚动
- 按类型（电影 / 剧集 / 综艺）、网盘、画质筛选，多维度排序
- 详情抽屉：模糊背景 hero、按网盘分组的链接、一键复制提取码

**智能解析**
- 从杂乱的资源标题中抽取片名、年份、季数、集数、分辨率、画质、语言字幕、体积
- 清洗结构性污染（冒号 / 井号 / 方括号 / 内嵌链接 / 整段元数据当标题）
- 同一作品的多个来源自动聚合去重，实测 937 条原始结果 → 508 部作品

**海报占位图**
- 无海报或加载失败时生成内联 SVG 占位图，不引外链
- 色相由标题哈希派生：同一部片颜色恒定，不同片大概率可区分
- 主图失败会沿备选图逐个回退，全失败才落到占位图

**播放跳转**
- 按优先级（夸克 → 阿里 → UC → 迅雷 → 123 → 115 → 百度…）挑选可在浏览器打开的网盘链接
- 有提取码时随提示一并给出
- 纯磁力 / 电驴资源无法在线播放，按钮显式禁用

**收藏与历史**
- localStorage 持久化，无后端依赖
- 打开详情或播放自动记录浏览历史，同一作品去重置顶
- 多标签页通过 `storage` 事件同步

**移动端适配**
- 13 个响应式断点，栅格四档自适应（≤380px 固定两列）
- 详情抽屉在窄屏变为底部弹出式 bottom-sheet
- 安全区适配、iOS 输入框防聚焦缩放、触屏常驻关键操作按钮

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物输出到 dist/
npm run preview  # 预览构建产物
```

构建产物是纯静态文件，可直接部署到任意静态托管。

## 配置

默认 API 基址为 `https://so.252035.xyz`，可在界面右上角「设置」中修改，会持久化到 localStorage。

界面提供「实时抓取」开关：
- 关闭（默认）：走后端缓存，秒回，但可能命中陈旧的空缓存
- 开启：后端实时扇出抓取，结果更全，但耗时可达 40 秒以上

## 关于数据源

后端返回的是网盘分享链接，不是可嵌入的视频流，因此「播放」的实际行为是在新标签页打开对应网盘页面，而非站内播放。

`res=results&src=all` 是当前稳定可用的取数参数组合。

## 本地播放（AList + PotPlayer）

点击播放默认会尝试走「本地 bridge 后端」：把网盘分享解析为直链并拉起本机 PotPlayer，
实现「页面内登录网盘 → 存储挂载到 AList → PotPlayer 播放」，无需二次跳转网盘官网。

### bridge 后端（零依赖，Python 标准库）

```bash
cd bridge
python run.py        # 默认监听 http://127.0.0.1:8787
```

前端通过 `VITE_BRIDGE_BASE` 指向它（默认 `http://127.0.0.1:8787`）。

### 使用流程

1. 页面右上角点「账号」→ 填写 **AList 地址 / 管理员账号 / 密码**（你的 AList 通常 `http://127.0.0.1:5244`）。
2. 填写 **PotPlayer 可执行文件路径**（如未自动探测到）。
3. 添加网盘账号：
   - **粘贴凭据**：夸克填 Cookie、阿里云盘填 refresh_token（一次填入，页面内管理）。
   - **二维码**：页面内展示登录二维码，手机扫码后自动落盘（夸克 / 阿里支持）。
4. 回到影视墙点任意作品的「播放」→ bridge 会按网盘类型：
   - 阿里云盘分享：免转存，直接挂载分享并解析直链；
   - 夸克等：把分享转存进你已挂载的盘，再解析直链；
   - 最后拉起 PotPlayer 播放该直链。
5. 若 bridge 未启动 / AList 未配置 / 解析失败，自动退回「新标签打开分享页」。

> 说明：夸克转存 API 与二维码登录依赖各网盘未公开接口，端点为社区已知形态，
> 若字段变动请在 `bridge/providers.py`、`bridge/transfer.py` 中按返回错误微调。
> 凭据仅存于本地 `bridge/bridge_data.json`（已加入 .gitignore），不会上传。
